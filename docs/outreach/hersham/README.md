# Hersham outreach

Working file for Phase 6 of `docs/hersham-head-term-plan.md`. Started 6 September 2026.

**What this is for.** The Hersham cluster is now twenty pages of sourced local content, and none of it earns a link by existing. The plan's own diagnosis stands: the hub can be beaten on links long before it is beaten on content, and the target from the extension's section 6 is **ten new referring domains within six months**.

**Division of labour.** Claude drafts, Darren sends. Nothing in here goes out automatically, and no message should be sent without Darren reading it first, because every one of them is an approach from a named person to a named person in a small village.

## Rules

These are not stylistic preferences. Getting them wrong makes the site look like every SEO outreach campaign that local organisations already delete unread.

1. **Offer a specific page that the recipient's own readers would want.** Never "please link to our Hersham guide". If there is no page that genuinely serves their audience, they are not a target yet.
2. **Disclose the connection every time.** Darren runs the site. Say so in the first two sentences, in every message and on every Talk page.
3. **Invite correction before asking for anything.** The strongest opening is that we have published something about them and would like to know if any of it is wrong. That is also true, which is why it works.
4. **No paid links, no link exchanges, no directory submissions, no comment drops.** A reciprocal-link offer is a link scheme and would put the whole domain at risk for a handful of links worth nothing.
5. **Never edit Wikipedia to add our own link.** Talk page, with disclosure, and leave the decision to editors. See the note in this month's batch.
6. **Log everything, including silence.** A target that ignored two approaches is not approached a third time. Refusals are recorded so nobody re-runs them next quarter.
7. **Five targets a month.** More than that reads as a campaign, and the small-village grapevine is real.

## What counts as success

A referring domain, not a mention. Track new linking domains in the monthly Search Console session described in Phase 7. Two of the five targets in a month replying at all would be a good rate; two linking would be an excellent one.
